# SAK EMKM - Bab 4: Pos-pos Laporan Keuangan

## Ringkasan Pos-pos Utama

Bab ini di SAK EMKM asli menjabarkan definisi dan perlakuan tiap pos
laporan keuangan. Untuk detail masing-masing pos, lihat file terpisah
di folder `accounting/` yang sudah disusun sesuai pos-pos berikut:

| Pos Laporan Keuangan | Referensi Detail |
|---|---|
| Aset | `accounting/15_aset.md` |
| Persediaan | `accounting/20_persediaan.md` |
| Piutang | `accounting/21_piutang.md` |
| Aset Tetap & Penyusutan | `accounting/23_penyusutan.md` |
| Liabilitas | `accounting/16_liabilitas.md` |
| Utang Usaha | `accounting/22_utang.md` |
| Modal (Ekuitas) | `accounting/17_modal.md` |
| Pendapatan | `accounting/18_pendapatan.md` |
| Beban | `accounting/19_beban.md` |

## Prinsip Umum Pos-pos Laporan Keuangan SAK EMKM

1. **Diukur dengan biaya historis** — dicatat sebesar kas/setara kas
   yang dibayarkan/diterima saat transaksi terjadi, tidak direvaluasi
   ke nilai pasar terkini secara rutin (beda dengan SAK Umum yang untuk
   pos tertentu mengharuskan nilai wajar).
2. **Diakui berdasarkan substansi ekonomi**, bukan sekadar bentuk hukum
   formalnya — meski untuk skala UMKM biasanya keduanya sejalan.
3. **Konsisten antar periode** — metode pengukuran (mis. metode
   penyusutan garis lurus) yang dipilih sebaiknya dipakai terus-menerus,
   tidak berganti-ganti tanpa alasan kuat.

## Klasifikasi Aset dan Liabilitas: Lancar vs Tidak Lancar

SAK EMKM mengizinkan klasifikasi aset/liabilitas sebagai lancar (jatuh
tempo/dikonsumsi ≤ 1 tahun) dan tidak lancar (> 1 tahun) untuk
mempermudah analisis likuiditas usaha — lihat detail per pos di file
`accounting/` masing-masing.

## Contoh Penerapan Lengkap

Untuk melihat bagaimana seluruh pos-pos ini terangkai jadi satu set
laporan keuangan yang utuh, lihat `contoh_laporan.md` di folder ini.
