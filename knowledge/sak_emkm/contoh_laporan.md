# Contoh Laporan Keuangan Lengkap Sesuai SAK EMKM

Contoh ilustratif untuk "Usaha Dagang Toko Budi" periode Juli 2026,
menggabungkan seluruh tahapan siklus akuntansi jadi satu set laporan
keuangan yang utuh.

## Ringkasan Transaksi Bulan Juli 2026

1. Setoran modal awal pemilik: Rp10.000.000 (tunai)
2. Beli perlengkapan tunai: Rp1.000.000
3. Penjualan tunai: Rp3.000.000
4. Bayar sewa toko: Rp500.000
5. Penyesuaian akhir bulan: perlengkapan terpakai Rp400.000

## 2. Laporan Laba Rugi — Periode Juli 2026

```
Pendapatan Penjualan                    3.000.000
(-) Beban Operasional
    Beban Sewa               500.000
    Beban Perlengkapan       400.000
    Total Beban Operasional             (900.000)
= Laba Bersih                           2.100.000
```

## 3. Laporan Perubahan Modal — Periode Juli 2026

```
Modal Awal (setoran awal)              10.000.000
(+) Laba Bersih Juli 2026               2.100.000
(-) Prive                                       0
= Modal Akhir per 31 Juli 2026         12.100.000
```

## 4. Laporan Posisi Keuangan — per 31 Juli 2026

```
ASET                                  MODAL
Kas                    11.500.000     Modal Pemilik      10.000.000
Perlengkapan               600.000    Laba Berjalan       2.100.000
Total Aset              12.100.000    Total Modal        12.100.000
```

**Aset (12.100.000) = Liabilitas (0) + Modal (12.100.000)** ✓ Balance.

## 5. Catatan atas Laporan Keuangan (CALK) — Ringkas

1. Laporan keuangan disusun sesuai SAK EMKM, dasar biaya historis, basis
   akrual, mata uang Rupiah.
2. Pendapatan diakui saat barang diserahkan ke pelanggan.
3. Beban diakui saat terjadi.
4. Perlengkapan dinilai sebesar biaya perolehan, dibebankan sesuai
   pemakaian aktual di akhir periode.

Ini contoh minimal untuk usaha yang baru mulai — di praktik nyata,
biasanya ada lebih banyak transaksi dan pos (Persediaan, Piutang, Utang,
Aset Tetap dengan penyusutan) seperti dicontohkan di
`accounting/24_contoh_transaksi.md`.
