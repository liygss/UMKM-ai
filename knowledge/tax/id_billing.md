# Pengertian
ID Billing atau Kode Billing adalah kode identifikasi pembayaran pajak yang diterbitkan oleh sistem Direktorat Jenderal Pajak (DJP) melalui Sistem Billing Pajak. Kode ini digunakan sebagai identitas transaksi saat Wajib Pajak akan melakukan pembayaran pajak. Setiap ID Billing bersifat unik dan hanya berlaku untuk satu jenis pembayaran pajak sesuai dengan data yang telah diinput oleh Wajib Pajak.

#Fungsi
ID Billing berfungsi untuk:
- Menjadi identitas transaksi pembayaran pajak.
- Mempermudah proses pembayaran pajak secara elektronik.
- Memastikan pembayaran tercatat pada jenis pajak yang benar.
- Mengurangi kesalahan dalam proses pembayaran pajak.
- Menghubungkan data pembayaran dengan sistem penerimaan negara.

# Informasi yang Terdapat dalam ID Billing
Saat membuat ID Billing, Wajib Pajak akan mengisi beberapa informasi, antara lain:
- NPWP.
- Nama Wajib Pajak.
- Jenis Pajak (KAP).
- Kode Jenis Setoran (KJS).
- Masa Pajak.
- Tahun Pajak.
- Jumlah pajak yang akan dibayar.
- Uraian pembayaran.

# Cara Membuat ID Billing
ID Billing dapat dibuat melalui:
- DJP Online.
- Coretax DJP.
- Penyedia Jasa Aplikasi Perpajakan (PJAP).
- Bank atau kanal resmi yang bekerja sama dengan DJP.

Langkah umum:
1. Login ke layanan resmi DJP.
2. Pilih menu e-Billing atau pembuatan Kode Billing.
3. Masukkan data pembayaran pajak.
4. Sistem menghasilkan ID Billing.
5. Gunakan ID Billing untuk melakukan pembayaran melalui kanal pembayaran resmi.

ID Billing memiliki masa berlaku sesuai ketentuan yang ditetapkan oleh DJP. Apabila melewati masa berlaku dan belum digunakan untuk pembayaran, Wajib Pajak perlu membuat ID Billing baru.
Pelaku UMKM yang memiliki kewajiban membayar pajak harus membuat ID Billing terlebih dahulu sebelum melakukan pembayaran. Setelah pembayaran berhasil, sistem akan menerbitkan Nomor Transaksi Penerimaan Negara (NTPN) sebagai bukti pembayaran yang sah.
